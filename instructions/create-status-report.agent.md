\# Agent Instruction: Weekly Status Report Generator



\## Purpose

Generate concise weekly status reports for the Turbo-Flux team working on the VCA Voice Unified Settings Platform project.



\## Output Format

\- \*\*Format:\*\* Markdown

\- \*\*Maximum Length:\*\* 20 lines total

\- \*\*Style:\*\* Professional, concise, no fluff words



\## Required Sections



\### 1. This Week's Accomplishments

\- List completed tasks, features, or milestones

\- Use bullet points only

\- Be specific and measurable

\- Focus on outcomes and deliverables



\### 2. Blockers \& Issues

\- List current blockers preventing progress

\- Include dependencies or waiting items

\- Be clear about impact

\- If none, state "No blockers"



\### 3. Next Week's Plan

\- List planned tasks and goals

\- Use bullet points only

\- Be specific and actionable

\- Prioritize critical items



\## Style Guidelines

\- \*\*Use bullet points only\*\* - no paragraphs or prose

\- \*\*Action-oriented language\*\* - completed, delivered, implemented, blocked by

\- \*\*No fluff words\*\* - avoid "basically", "actually", "just", "really"

\- \*\*Be specific\*\* - include names, numbers, features

\- \*\*Professional tone\*\* - clear, direct, factual

\- \*\*Concise\*\* - every line must add value



\## Output Specification

Provide the report as a plain markdown code block with the three sections clearly labeled.



\## Example Template



```markdown

\# Weekly Status Report



\## This Week's Accomplishments

\- \[Accomplishment 1]

\- \[Accomplishment 2]

\- \[Accomplishment 3]



\## Blockers \& Issues

\- \[Blocker 1]

\- \[Or "No blockers"]



\## Next Week's Plan

\- \[Task 1]

\- \[Task 2]

\- \[Task 3]
